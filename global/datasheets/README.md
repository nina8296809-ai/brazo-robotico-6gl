# Datasheets

Hojas de datos de los componentes del brazo. Son del equipo, no de un semestre.

Archivos esperados: PIC16F1946, drivers 2M542-N y 2MA320, motores NEMA 23 (57J1854-828), NEMA 17 (42J1848-604) y NEMA 16, sensores NJK-5002C y finales de carrera M102-011.

Después de subir un datasheet, indique en `config/archivos.json` su título y a qué ejes corresponde (los nombres de archivo de los fabricantes no traen esa información).

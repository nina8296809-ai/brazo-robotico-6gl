guia de instalacion, programas para el brazo de 6 grados de libertad
nota: los programas y clave de activacion fueron obtenidos de la pagina oficial de Microchip (www.microchip.com) 
1- Instalar el compilador Hi-Tech C (programa picc_9.83_win.exe)
	- active la opcion Activate PRO/Standard mode with serial number:
	- introduzca la clave de activacion: HCPICP - 101216802-4832
	- acepte las condiciones de licencia
2- Instalar el IDE (MPLABX-v5.10-windows-installer.exe)
	- no requiere clave de activacion
3- Instalar el software del programador PICkit 3 (PICkit3Setup.msi)
	- descomprimir la carpeta PICkit3 Programmer Application v3.10.zip
	- descomprimir la carpeta PICkit3 Programmer Application Setup v3.10.zip
	- instalar el programa PICkit3Setup.msi

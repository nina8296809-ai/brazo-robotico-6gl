# II-2026

Semestre en curso. Todo el material de este semestre se sube aquí, sin Google Drive (salvo videos, que van a YouTube y se registran en `config/videos.json`).

| Carpeta | Qué va |
|---------|--------|
| `guias` | Guías de laboratorio del semestre. |
| `ingenieria-inversa` | Revisión de componentes y estado inicial del brazo. |
| `diagnostico` | Fotos de fallas encontradas, cada una con su descripción en `config/archivos.json`. |
| `mapeo-hardware` | Pines del PIC, conexiones a drivers y sensores. |
| `diagramas` | Diagrama de estados, diagramas de flujo y de bloques. |
| `planos/electrico` | Planos eléctricos (`.dwg` para descargar y `.pdf` para ver). |
| `firmware` | Proyecto de MPLAB X: archivos `.c`, `.h` y el `.hex` final. |
| `cinematica` | Parámetros de Denavit-Hartenberg, cinemática directa e inversa. |
| `pruebas` | Ensayos en `.csv` (la página los grafica). |
| `informes` | Informes de laboratorio en PDF. |
| `presentaciones` | Diapositivas. |

Para que un archivo se asigne a un eje, incluya `eje1` … `eje6` en el nombre: `eje2_hombro_prueba_velocidad.csv`.

# Base de datos (ETN-1000)

Scripts SQL y modelo de datos del brazo: por ejemplo, registro de posiciones de cada eje, secuencias ejecutadas, pruebas y fallas.

- Los archivos `.sql` aparecen en la pestaña **Programas**, en el grupo "SQL", y se pueden leer con colores en la página.
- El diagrama entidad-relación puede subirse como imagen, PDF o `.drawio`.
- Nombre sugerido con número de orden: `01_esquema.sql`, `02_datos_prueba.sql`, `03_consultas.sql`.
